# {{name}}

Java / Spring AI agent for Amazon Bedrock AgentCore Runtime, generated by agentcore-cli.

## Prerequisites

- JDK 21
- Maven 3.9+
- `AWS_REGION`
- AWS credentials with Bedrock access for live model invocations

## Run locally

```bash
AWS_REGION=us-west-2 mvn spring-boot:run
curl localhost:8080/ping
curl -N localhost:8080/invocations \
  -H 'Content-Type: application/json' \
  -H 'Accept: text/event-stream' \
  -d '{"prompt":"hi"}'
```

`agentcore dev` starts the same `mvn spring-boot:run` process and restarts it on demand. It does not provide hot reload.

If `MEMORY_<NAME>_ID` is set, the agent validates the memory at startup and exits on failure.
